# Plan Drawer — ระบบวาด Polygon บนแปลนโครงการบ้านจัดสรร

เว็บแอปสำหรับวาดและจัดการแปลง/พื้นที่บนรูปผังโครงการ เขียนด้วย HTML/CSS/JavaScript ล้วน ไม่ต้อง build และไม่มี dependency

## วิธีเปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือรันผ่าน local server:

```bash
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```

## ส่วนประกอบหน้าจอ

| ส่วน | รายละเอียด |
|---|---|
| **Ribbon (บนสุด)** | แท็บ *หน้าแรก / แปลน / มุมมอง* แบบ Microsoft Office มีทั้งปุ่มใหญ่ที่มีไอคอน และปุ่มเล็ก ชี้ค้างเพื่อดู tooltip พร้อมคีย์ลัด |
| เครื่องมือวาด | เลือก/แก้ไข (V) · เลื่อนแผนที่ (H) · สี่เหลี่ยม (R) · Polygon (P) · ปักไอคอน (I) พร้อมแกลเลอรีไอคอน 12 แบบ |
| แก้ไข | เลิกทำ / ทำซ้ำ / ทำสำเนา / ลบที่เลือก |
| หมุนแปลน | หมุนซ้าย-ขวา 90°, ใส่องศาละเอียด, slider หมุนในแท็บ “แปลน” (รูปที่วาดจะหมุนตาม) |
| สถานะแปลง | ว่าง · จองแล้ว · ขายแล้ว · กำลังก่อสร้าง · ส่วนกลาง (คลิกเพื่อใช้กับแปลงที่เลือก และเป็นสถานะของรูปที่วาดใหม่) |
| **ตัวเลือก Unit / ชั้น (มุมขวาล่าง)** | แบบ Google Maps indoor — เลือก Unit/โซน (เพิ่ม/เปลี่ยนชื่อได้) และชั้น 1–4 ชั้นที่มีข้อมูลจะมีจุดสีเขียว พร้อมเข็มทิศและปุ่มซูม |
| **แผงด้านขวา** | คุณสมบัติของรายการที่เลือก (ชื่อ สถานะ ราคา พื้นที่ หมายเหตุ) สรุปจำนวนแปลงตามสถานะ และรายการแปลงที่ค้นหา/กรองได้ |
| **Historical timeline (ล่างสุด)** | ทุกการเปลี่ยนแปลงถูกบันทึกเป็นจุดบนเส้นเวลา คลิกเพื่อดูย้อนหลัง, เล่นอัตโนมัติ, “เทียบกับปัจจุบัน” (เส้นประซ้อน), และ “คืนค่าเวอร์ชันนี้” แบบไม่ลบประวัติ |

## ความสามารถที่ช่วยให้ใช้ง่าย

- ลากไฟล์ภาพมาวางบนพื้นที่วาดได้ทันที หรือกด “ใช้ภาพตัวอย่าง” เพื่อทดลอง
- แถบคำแนะนำลอยด้านบนบอกขั้นตอนของเครื่องมือที่ใช้อยู่
- แก้รูปร่าง: ลากจุดสีขาว, ลากจุดสีฟ้ากลางขอบเพื่อเพิ่มจุด, ดับเบิลคลิกจุดเพื่อลบ
- Polygon: คลิกจุดแรก / ดับเบิลคลิก / Enter เพื่อจบ, Backspace ลบจุดล่าสุด, ลากระหว่างวาดเพื่อเลื่อนแผนที่ได้
- หมุนแปลนให้ตรงก่อน แล้ววาดสี่เหลี่ยมให้ขนานกับแปลงได้พอดี
- ตั้งมาตราส่วน (1 ม. = กี่ px) เพื่อดูพื้นที่เป็น ตร.ม. และ ไร่-งาน-ตร.วา
- บันทึกอัตโนมัติในเบราว์เซอร์ (localStorage + IndexedDB สำหรับภาพ), ส่งออก/นำเข้าโปรเจกต์เป็น `.json`, บันทึกเป็นภาพ PNG
- รองรับเมาส์ ทัชแพด และจอสัมผัส (ลากสองนิ้วเพื่อซูม) กด `?` เพื่อดูคีย์ลัดทั้งหมด

## โครงสร้างไฟล์

```
index.html      โครงหน้าจอ (ribbon, stage, ตัวเลือกชั้น, แผงด้านขวา, timeline)
css/styles.css  สไตล์ทั้งหมด
js/icons.js     ชุดไอคอน SVG
js/sample.js    สร้างภาพผังตัวอย่าง
js/app.js       state, การวาด, undo/redo, timeline, การบันทึก
```
